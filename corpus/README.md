# Layer 2 retrieval corpus

Curated, versioned data that grounds every paid-report explanation and rewrite
(`technical_architecture.md` §5, `data_model.md` §6). Loaded by `atsc.deep.corpus`,
indexed in-process by `atsc.deep.retrieval`. Nothing here is generated by a model.

```
bullets/<category>.yaml   strong bullet examples and weak→strong rewrite pairs, per cluster
platforms.yaml            ATS platform behaviours, each with its source
guidance.yaml             writing guidance for ML / DS / AI resumes
```

Taxonomy equivalence chunks ("LoRA is also written as …") are derived from `taxonomy/`
at load time, so they never drift from the matcher.

Rules:
- Every `cluster_id` must exist in the taxonomy; the loader refuses unknown ids.
- Each cluster keeps at least two strong bullets (tested). Bullets are illustrative,
  not copied from any real resume, and every one names a method, a scale and an outcome.
- Platform claims stay within what `docs/resume_parsing_spec.md` §3 states; cite it.
- A rewrite pair's stronger version must be plausibly true of the weak one, not an
  embellishment: the report must never coach users into claims they cannot back.
